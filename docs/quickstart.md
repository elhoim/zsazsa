# Quickstart

The quickstart is on the zsazsa website: [zsazsa-project.org/documentation.html](https://zsazsa-project.org/documentation.html).

It takes you from a fresh checkout to a first daily threat briefing delivered to a stakeholder, in three steps: install zsazsa with Docker or next to MISP, configure it with the setup wizard, and run it. [INSTALL.md](../INSTALL.md) has the installation in full, and [Configuration](../README.md#configuration) in the README describes every setting.
